# 千问办公绿皮书导航架构改版

## 目标

让访客能清楚区分三条主线：官方学习路径、按任务找入口、真实案例复现；删除已经不再承担内容职责的“工作评测”和 Phase 4 入口。

## 信息架构

```text
开始
├── 首页
└── 完整目录
阅读路径
├── 路径总览
├── Phase 1 · 新手入门
├── Phase 2 · 核心功能
└── Phase 3 · 常见任务与场景实战
实战案例分享
├── 案例 01 · 小明的交付升级记
│   ├── 序章
│   └── 第一章—第六章
├── 案例 02—07 · 其他案例（并列）
└── 任务素材入口
任务速查
└── 按交付类型跳转官方教程，并进入相关案例素材
深度
├── 方法论
└── 关于绿皮书
```

## 规则

- Phase 1–3 的命名和官方文档层级保持一致。
- 实战案例是独立内容主线，不再被称为 Phase 4。
- 任务速查保持单页，不新增左侧子菜单。
- 小明是重点案例，但不能吞掉其他六个案例的并行入口。
- “工作评测”和“设计参考资料”不出现在公开主导航或页脚。
- 原有案例文件和 `eval.html` 暂不删除，仅移除公开入口，避免破坏可恢复性。
