# 信息源与筛选规则｜可追溯版

## 信息源优先级

1. 品牌官网、官方公众号、发布会材料、应用商店更新说明；
2. 手机厂商或硬件厂商的官方公告、开发者文档和产品页面；
3. 有明确记者、日期和原文链接的行业媒体；
4. 用户帖子、视频和论坛讨论，仅作为线索，不直接作为事实结论；
5. 无来源转载、标题党或无法打开的截图，不作为确认依据。

## 每条新闻必须保留的字段

| 字段 | 要求 |
|---|---|
| 发生日期 | 区分发布时间与事件发生时间 |
| 品牌/产品 | 使用清晰对象，不能只写“某厂商” |
| 事件类型 | 发布、更新、合作、融资、用户反馈或传闻 |
| 原文事实 | 只写来源明确说了什么 |
| 来源 | URL、文章标题、截图或官方文件 |
| 可信度 | 已确认 / 多源报道 / 待核验 |
| 可能影响 | 单独写成推断，并标记“待判断” |
| 下一步 | 需要谁在何时核验什么 |

## 去重规则

- 同一官方公告被多家媒体转载，只保留官方源，媒体放在补充来源；
- 同一事件有新信息时，写成“更新”，不要重复生成一条相同新闻；
- 传闻和官方确认不能合并为一条“事实”。

## 不允许的表达

- 不把“可能、据称、网传”改写成“已经”；
- 不从一条新闻直接推导销量、市场份额或用户增长；
- 不把 AI 生成的影响判断当作企业战略事实；
- 不在没有人工核验时自动推送高风险内容。
