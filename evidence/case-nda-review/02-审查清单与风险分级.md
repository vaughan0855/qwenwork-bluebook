# NDA 审查清单与风险分级｜演示版

## 审查维度

| 维度 | 需要看什么 | 常见追问 |
|---|---|---|
| 保密信息范围 | 是否过宽、是否包含已公开信息 | 是否能按项目或资料类型限定 |
| 使用目的 | 是否仅限当前合作 | 能否用于内部评估、关联方协作 |
| 例外条款 | 是否覆盖先前知悉、独立开发、合法取得 | 证明责任由谁承担 |
| 接收人员 | 员工、关联方、顾问、供应商能否接触 | 是否需要逐一取得承诺 |
| 期限 | 协议期限与保密义务期限 | 商业秘密是否需要更长期限 |
| 返还删除 | 时间、备份、法定留存 | 是否有可执行的删除证明 |
| 违约责任 | 违约金、实际损失、责任上限 | 是否对双方对称 |
| 知识产权 | 是否误写成成果归属或授权 | 项目成果是否另有协议 |
| 争议解决 | 法律适用、管辖地、仲裁/诉讼 | 对我方成本和执行有什么影响 |

## 风险分级

- **红色｜需法务明确确认**：可能影响责任、知识产权、商业秘密、数据合规或诉讼成本；不应由 AI 给出“可签”。
- **黄色｜建议谈判或补充**：条款存在不清晰、不对称或执行难点，需要业务与法务共同决定。
- **绿色｜文本层面可接受**：从演示清单看未发现明显冲突，但仍不等于法律审查通过。
- **灰色｜资料不足**：需要补充交易背景、披露信息类型、对方身份或公司内部底线。

## 输出要求

每个判断都要同时保留：条款位置、原文摘录、风险理由、建议动作和人工确认人。
