# 验收标准｜NDA 初审底稿

## 可追溯

- 每一个风险判断都能回到具体条款位置和原文摘录；
- 每一个修改建议都能说明解决什么问题；
- 没有原文依据的判断必须标记为资料不足或待法务确认。

## 不越界

- 不输出“法律上一定有效/无效”的结论；
- 不直接替代律师给出最终签署意见；
- 不代替业务决定价格、责任上限、管辖地或项目成果归属；
- 不把红黄绿颜色当成法律风险的自动裁判。

## 交付可用

- 业务方能在 3 分钟内看懂最需要关注的 3 个问题；
- 法务能快速定位原文、风险理由和待确认事项；
- 页面明确标注虚构脱敏示例和“仅供专业人士复核”；
- 对外发送的修改稿必须经过人工终审。
