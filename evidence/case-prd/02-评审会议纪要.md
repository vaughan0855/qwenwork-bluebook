# 需求评审会议纪要（脱敏示例）

> 会议日期：2026-08-26
> 资料性质：合成实验资料

## 已达成共识

1. 一期目标是减少“沟通后没有下一步动作”的情况；
2. 首版至少包含：最近一次沟通摘要、下一步动作、负责人、提醒日期、完成状态；
3. 逾期提醒先做站内提醒，不承诺自动发钉钉；
4. 客户分层和自动推荐回访周期放到后续评估。

## 尚未决定

- 是否允许一个客户同时有多个未完成回访任务；
- “完成”是否必须填写结果说明；
- 提醒日期是否允许早于今天；
- 谁可以修改他人的回访记录。

## 评审人要求

下次 PRD 需要把“用户故事—功能—验收条件”对上，不能只有功能列表。
